# Tirupati Creations — Website Project

A responsive, luxury-inspired website for Tirupati Creations, built with HTML, CSS and vanilla JavaScript. The design uses an espresso-black, champagne-gold and warm-ivory palette.

## Project files

- `index.html` — website content and page structure
- `style.css` — layout, colours, typography and responsive styling
- `script.js` — mobile navigation and automatic copyright year

## Add your photographs

The original website referred to these image files. Copy them into this same project folder, keeping the exact filenames and letter case:

- `6.png` — homepage hero photograph
- `4.png` — premium cotton kurtis
- `3.jpeg` — kurti sets
- `1.jpeg` — new arrivals
- `5.png` — about/story photograph

The page has decorative fallbacks if an image is missing, but your own photographs will make the finished assignment look much better. Keep the image files in the same folder as `index.html`.

## Preview on your computer

1. Extract the ZIP file.
2. Put your five image files in the project folder if available.
3. Double-click `index.html` to open it in your browser.

No build tools or installation are required.

## GitHub repository

This project is stored in the public `Tirupati-Creations` repository. The source files are `index.html`, `style.css`, `script.js`, and this README.

## Publish with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then save.
4. Wait for GitHub Pages to finish publishing. The live website link will appear in the Pages section.

## Photographs

The HTML references optional image files named `6.png`, `4.png`, `3.jpeg`, `1.jpeg`, and `5.png`. Add your own photographs with these exact names to the repository root. Until then, styled image placeholders appear automatically.
